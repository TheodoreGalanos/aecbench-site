aec-bench is a Python platform for creating, versioning, running, evaluating, and improving Architecture, Engineering and Construction benchmark tasks for AI agents.

Use these docs to move from a first local run to maintaining reproducible benchmark datasets, agent harnesses, evaluation traces, and leaderboard-ready results.

## Recommended paths

- New to aec-bench: start with [Quickstart](/docs/start/quickstart).
- Writing benchmark content: read [Tasks](/docs/core/tasks), [Templates](/docs/core/templates), and [Datasets](/docs/advanced/datasets).
- Running agents: read [Harnesses](/docs/agents/harnesses), [Configuration](/docs/agents/configuration), and [Environment](/docs/reference/environment).
- Reviewing results: read [Scoring](/docs/evaluation/scoring), [Traces](/docs/evaluation/traces), and [Classification](/docs/evaluation/classification).
- Publishing or integrating: read [Library Catalogue](/docs/reference/library-catalogue) and [Prime Lab](/docs/advanced/prime-lab).
