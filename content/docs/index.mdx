aec-bench is a Python platform for creating, running, evaluating, and improving Architecture, Engineering and Construction benchmark tasks for AI agents.

Use these docs to move from a first local run to maintaining reproducible benchmark datasets, agent harnesses, evaluation traces, and leaderboard-ready results.

## Recommended paths

- New to aec-bench: start with [Quickstart](/docs/start/quickstart).
- Writing artefact tasks: read [Tasks](/docs/core/tasks), [Templates](/docs/core/templates), [Contributing Tasks](/docs/core/contributing), and [Datasets](/docs/advanced/datasets).
- Writing staged or stateful tasks: read [Finite Lifecycles](/docs/core/lifecycles) and [Interactive Worlds](/docs/core/interactive-worlds).
- Running agents: read [Harnesses](/docs/agents/harnesses), [Configuration](/docs/agents/configuration), [Prime Agent](/docs/agents/prime-agent), and [Environment](/docs/reference/environment).
- Reviewing results: read [Scoring](/docs/evaluation/scoring), [Traces](/docs/evaluation/traces), [Classification](/docs/evaluation/classification), and [Review and Reporting](/docs/evaluation/reviewing).
- Developing harnesses and governed workflows: read [Meta-Harness Composition](/docs/advanced/meta-harness-runtime), [Adaptive Harnesses](/docs/advanced/adaptive-harnesses), and [Evolution](/docs/advanced/evolution).
- Publishing or integrating: read [Library Catalogue](/docs/reference/library-catalogue) and [Prime Lab](/docs/advanced/prime-lab).
